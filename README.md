# bas_runtime
Runtime обработки изображений для платы luckfox-pico-pro-max

## Конфигурация

Настройки рантайма читаются из `config.ini` в рабочем каталоге: он лежит рядом с бинарником
и ставится вместе с ним. Ключ можно не указывать — отсутствующий ключ и значение, которое
не удалось разобрать, заменяются значением по умолчанию из кода. Сам файл должен существовать
и быть синтаксически корректным, иначе программа сообщает об ошибке и не запускается.

Состав ключей и их значения по умолчанию описаны в [config.ini](./config.ini).
