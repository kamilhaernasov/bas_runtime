# bas_runtime
Runtime обработки изображений для платы luckfox-pico-pro-max

## Конфигурация

Настройки рантайма читаются из `config.ini`, настройки модели — из `model.ini`; оба лежат
рядом с бинарником и ставятся вместе с ним. Ключ можно не указывать — отсутствующий ключ
и значение, которое не удалось разобрать, заменяются значением по умолчанию из кода.
Сами файлы должны существовать и быть синтаксически корректными, иначе программа сообщает
об ошибке и не запускается.

`config.ini` — камера, кодирование и RTSP. `model.ini` — тип модели, файл `.rknn`, размер
его входа, пути до файлов с названиями классов и якорями, а также ручки детекции
(пороги и лимит рамок). Реализация разбора выходов выбирается ключом `type`; под YOLOv5
это `br_model_yolo`.

Состав ключей и значения по умолчанию описаны в [config.ini](./config.ini) и [model.ini](./model.ini).

## Отладка кадров

Под определением `debug_frame` рантайм печатает строку на каждый кадр: времена стадий
(`vi`, `rga`, `npu`, `draw`, `flush`, `venc`, `rtsp`) в миллисекундах и число детекций.
Определение выключено по умолчанию и включается при сборке:

```bash
cmake -S . -B build -DDEBUG_FRAME=ON && cmake --build build && cmake --install build
```
